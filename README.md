# Basketball-Scratch-Game
An interactive arcade game built in Scratch featuring custom collision detection, and score tracking which is built for Harvard University CS50x (problem 0)
🎮 How to Play
1. Download `Basketball-Game.sb3` from this repository.
2. Go to [Scratch Editor](https://scratch.mit.edu/projects/editor/).
3. Click **File** > **Load from your computer** and select the downloaded file.
