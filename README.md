# Basketball-Scratch-Game

An interactive arcade game built in Scratch featuring custom collision detection and score tracking, built for Harvard University CS50x (Problem 0).

## 🎮 How to Play
1. Download `https://github.com/me50/SahibjeetGuraya/blob/cs50/problems/2026/x/scratch/Untitled%20(1).sb3 
2. Go to the [Scratch Editor](https://scratch.mit.edu/projects/editor/).
3. Click **File** > **Load from your computer** and select `Basketball-Game.sb3`.
