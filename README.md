# Basketball-Scratch-Game

An interactive arcade game built in Scratch featuring custom collision detection and score tracking, built for Harvard University CS50x (Problem 0).

## 🎮 How to Play
1. Click [here to download Basketball-Game.sb3](https://raw.githubusercontent.com/SahibjeetGuraya/Basketball-Scratch-Game/main/Untitled%20(1).sb3) directly to your device.
2. Go to the [Scratch Editor](https://scratch.mit.edu/projects/editor/).
3. Click **File** > **Load from your computer** and select the downloaded `.sb3` file.
