# Basketball-Scratch-Game

An interactive arcade game built in Scratch featuring custom collision detection and score tracking, built for Harvard University CS50x (Problem 0).

## 🎮 How to Play
1. Download the game file (`.sb3`) from the repository files list above.
2. Open the [Scratch Editor](https://scratch.mit.edu/projects/editor/).
3. Click **File** > **Load from your computer** and select the `.sb3` file.
