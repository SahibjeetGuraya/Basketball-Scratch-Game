# Basketball-Scratch-Game

An interactive arcade game built in Scratch featuring custom collision detection and score tracking, built for Harvard University CS50x (Problem 0).

## 🎮 How to Play
1. Tap `Untitled (1).sb3` in the file list above, then tap the top-right `...` menu to download/save the file.
2. Go to [Scratch Editor](https://scratch.mit.edu/projects/editor/).
3. Click **File** > **Load from your computer** and select the downloaded file.
